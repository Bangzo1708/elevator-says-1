A Python program that writes the funniest thing a talking elevator would say, in the elevator's own voice, to /output/entry.txt. Three candidate lines are scored 0-5 against the judge's five criteria - funniest line, joke lands on first read, voice from the elevator's own job, every word working, fresh idea - and the strongest one wins, deterministically (no randomness, no clock, no network).

## Run it

```sh
python3 main.py
```
